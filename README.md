Air Quality Data Analysis

Description

This project uses R to analyze air quality data from RDU Airport. It includes data cleaning, summary tables, and plots for CO, PM2.5, and O3.

Files

data/: Original CSV files

project 2.R: R code

project 2.Rmd: RMarkdown report

project 2.docx: Word report

Project2.Rproj: RStudio project

How to Run

Open Project2.Rproj in RStudio, then open project 2.Rmd and click Knit.
